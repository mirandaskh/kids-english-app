# 🌟 英语小学霸 · 背单词 & 时文阅读

一个专为小学生设计的英语学习网页应用,**无需安装任何软件**,双击打开即用,手机电脑都能跑。

![首页截图](https://img.shields.io/badge/%E6%8A%80%E6%9C%AF-%E7%BA%AFHTML%2FCSS%2FJS-orange)

## 🚀 如何打开

**⭐ 在线访问(手机推荐):[https://mirandaskh.github.io/kids-english-app/](https://mirandaskh.github.io/kids-english-app/)**

任意设备、任意网络直接打开;手机浏览器打开后可「添加到主屏幕」当 APP 用。

**方式一(离线):直接双击 `index.html`**,会用浏览器打开。

**方式二(局域网):** 启动本地服务器后,手机(同一 Wi-Fi)访问 `http://<电脑IP>:8765/`

```powershell
# 在项目目录执行(需要 PowerShell,Windows 自带)
powershell -NoProfile -ExecutionPolicy Bypass -File ..\serve.ps1
```

> 💡 两种方式都支持发音功能;数据保存在浏览器本地(localStorage),不会上传到任何服务器。
> 发音使用浏览器自带的语音引擎,建议使用 **Chrome / Edge / Safari** 打开。

## ✨ 功能总览

### 📖 背单词
- **词库**:人教版 PEP 小学英语 3~6 年级共 8 册,其中**五年级上册为 2024 新版教材附录单元词汇表**(Unit 1-6 共 119 词),教材**黑体词已标注 ⭐重点**
- **学新词**:卡片式学习,自动发音 + 音标 + 释义 + 例句,每次 10 个,支持按单元学习
- **去复习**:根据单词熟悉度智能安排,记牢的词慢慢减少,模糊的词反复出现
- **选一选**:中英双向选择题,答错自动进生词本
- **拼一拼**:听发音拼写单词,拼写更牢固
- **生词本**:测验/拼写答错的词自动收录,可发音跟读、移除、单独出题
- **单元筛选**:五年级上册可按 Unit 1-6 筛选学习、测验,筛选条上显示各单元进度

### 📰 时文阅读
- 8 篇分级英文短文(入门 / 进阶 / 挑战三级),题材贴近小学生生活
- **点词查义**:阅读时点击任何单词,弹出音标、释义、例句并可发音
- **全文翻译**:一键显示/隐藏每段中文翻译
- **朗读全文**:整篇朗读,可以跟读练听力
- **阅读理解**:每篇 3 道选择题,即时判分,记录最好成绩

### 🏅 成绩与激励
- 累计掌握单词数、连续打卡天数、读完文章数、学习天数
- 各册进度条 + 今日表现明细
- 🔥 连续打卡机制:每天学习自动延续

### ⚙️ 设置
- 发音语速(慢/正常/快)、自动朗读开关、试听
- 学习记录重置、数据导出备份(复制 JSON)

```
    ├── words.js        # 背单词模块

    └── app.js          # 首页 / 成绩 / 设置 / 导航
```

## 🔧 如何扩充内容

- **加单词**:编辑 `js/data-words.js`,在对应词书的 `words` 数组里添加:
  `{ w: '单词', p: '/音标/', m: '词性. 中文', s: '例句', u: 单元号(可选), k: 1(重点词,可选) }`
- **加文章**:编辑 `js/data-articles.js`,按现有格式添加段落(英/中)、生词表和 3 道题
- 想支持其他教材(外研社、译林等),复制一份词书对象改 id 即可

## ❓ 常见问题

- **没有声音?** 先点一下页面再点发音按钮;检查浏览器是否为 Chrome/Edge/Safari;部分浏览器需要在系统设置里开启文字转语音。
- **换设备/浏览器后进度没了?** 数据存在本地,可在「设置 → 导出/备份数据」复制 JSON 保存;换设备后可手动恢复(需要开发者支持)。
- **手机上怎么用?** 把 `kids-english-app` 文件夹传到手机,用手机浏览器打开 `index.html`;或在电脑上启动服务器后,手机连同一 Wi-Fi 访问电脑 IP。
